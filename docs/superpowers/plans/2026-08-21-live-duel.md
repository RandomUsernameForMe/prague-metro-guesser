# Živý duel 1v1 — implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dva hráči odehrají proti sobě 10 kol v reálném čase — společný časovač, shot clock 5 s po prvním odevzdání, po každém kole se ukáže, kdo byl blíž.

**Architecture:** Logika zápasu je čistá funkce `reduce(state, event, now) → {state, effects}` v `web/shared/duel-machine.mjs`, testovatelná v Node bez Cloudflare. `MatchDO` (Durable Object) je slupka: WebSocket, alarmy, storage, skórování a zápis do D1. `LobbyDO` páruje neznámé hráče. Klient dostane přes `web/board.mjs` (vytažené kreslení a odpočet) a `web/duel.mjs` (WebSocket a řízení duelu).

**Tech Stack:** Cloudflare Workers, Durable Objects se SQLite backendem a WebSocket Hibernation, D1, vanilla ES modules, `node --test`.

**Předpoklad:** Nejdřív musí být hotový `docs/superpowers/plans/2026-08-21-worker-migration.md` — bez Workeru nejde definovat třída Durable Objectu. Spec: `docs/superpowers/specs/2026-08-21-live-duel-design.md`.

## Známé omezení, které tenhle plán neřeší

`web/stations.json` je veřejný soubor a obsahuje `axes` — skutečné osy kolejí. Kdokoli si dnes umí skriptem vyřešit libovolné kolo v libovolném režimu, protože jméno stanice je součástí zadání a osy jsou v tom souboru. Duel na tom nic nezhoršuje ani nezlepšuje. Jediné, co serverový průběh zaručuje, je, že **nejdou předpočítat budoucí kola** (seed zůstává v DO) a **nejde odevzdat po deadline**. Skutečná obrana by znamenala `axes` z veřejného JSONu odstranit a posílat je až při odhalení — samostatná práce mimo tenhle plán.

```js
// Čistý stavový automat duelu. Nezná DOM, Cloudflare ani stanice — dostává
// jen délky kol a už spočítané skóre, takže se testuje obyčejným node --test.
export const COUNTDOWN_MS = 3000;
export const REVEAL_MS = 3000;
export const SHOT_CLOCK_MS = 5000;
export const GRACE_MS = 15000;
export const ROUND_MS = { single: 20000, transfer: 30000 };

export const roundMsFor = lineCount => (lineCount > 1 ? ROUND_MS.transfer : ROUND_MS.single);

// roundMs: pole délek kol v ms, jeho délka udává počet kol
export function initialState(code, roundMs) {
  return {
    code,
    roundMs,
    phase: 'waiting',      // waiting | countdown | drawing | reveal | paused | ended
    roundIndex: 0,
    deadline: 0,           // absolutní čas v ms; 0 = nic neběží
    players: {},           // id → {nick, connected, total, submitted, score}
    order: [],             // pořadí připojení, ['a', 'b']
    pausedPhase: null,
    pausedRemainingMs: 0,
    winner: null,
    reason: null,
  };
}

const send = (to, msg) => ({ type: 'send', to, msg });
const alarm = at => ({ type: 'alarm', at });

export const stateMsg = s => ({
  type: 'state',
  phase: s.phase,
  roundIndex: s.roundIndex,
  deadline: s.deadline,
  winner: s.winner,
  reason: s.reason,
  players: s.order.map(id => ({
    id,
    nick: s.players[id].nick,
    connected: s.players[id].connected,
    total: s.players[id].total,
    submitted: s.players[id].submitted,
  })),
});

export function reduce(state, event, now) {
  const s = structuredClone(state);
  const fx = [];
  switch (event.type) {
    case 'join': return join(s, event, now, fx);
    default: return { state, effects: fx };
  }
}

function join(s, { playerId, nick }, now, fx) {
  if (s.order.length >= 2) {
    fx.push(send(playerId, { type: 'error', error: 'full' }));
    return { state: s, effects: fx };
  }
  s.players[playerId] = { nick, connected: true, total: 0, submitted: false, score: 0 };
  s.order.push(playerId);
  if (s.order.length === 2) {
    s.phase = 'countdown';
    s.deadline = now + COUNTDOWN_MS;
    fx.push(alarm(s.deadline));
  }
  fx.push(send('all', stateMsg(s)));
  return { state: s, effects: fx };
}
```

V `web/shared/duel-machine.mjs` nahraď `switch` uvnitř `reduce`:

A přidej pod `join` tyhle funkce:

```js
function timeout(s, now, fx) {
  switch (s.phase) {
    case 'countdown': return startRound(s, 0, now, fx);
    case 'drawing': return endRound(s, now, fx);
    default: return { state: s, effects: fx };
  }
}

function startRound(s, i, now, fx) {
  s.phase = 'drawing';
  s.roundIndex = i;
  s.deadline = now + s.roundMs[i];
  for (const id of s.order) {
    s.players[id].submitted = false;
    s.players[id].score = 0;
  }
  fx.push(alarm(s.deadline), send('all', { type: 'round', i, deadline: s.deadline }));
  return { state: s, effects: fx };
}

function submit(s, { playerId, i, score }, now, fx) {
  const p = s.players[playerId];
  // pozdní, duplicitní i cizí kolo se tiše zahodí — kolo je pak za 0
  if (s.phase !== 'drawing' || i !== s.roundIndex || !p || p.submitted || now > s.deadline) {
    return { state: s, effects: fx };
  }
  p.submitted = true;
  p.score = score;
  if (s.order.every(id => s.players[id].submitted)) return endRound(s, now, fx);

  s.deadline = Math.min(s.deadline, now + SHOT_CLOCK_MS); // min, jinak by pozdní tip čas přidal
  fx.push(
    alarm(s.deadline),
    send('all', { type: 'opponent', id: playerId, connected: p.connected, submitted: true }),
    send('all', { type: 'deadline', i, deadline: s.deadline }),
  );
  return { state: s, effects: fx };
}

function endRound(s, now, fx) {
  const scores = {}, totals = {};
  for (const id of s.order) {
    const p = s.players[id];
    p.total += p.score;   // kdo neodevzdal, má score 0 z startRound
    scores[id] = p.score;
    totals[id] = p.total;
  }
  s.phase = 'reveal';
  s.deadline = now + REVEAL_MS;
  fx.push(alarm(s.deadline), send('all', { type: 'reveal', i: s.roundIndex, scores, totals }));
  return { state: s, effects: fx };
}
```

Pozor na test „třetí hráč dostane chybu": `reduce` musí u neznámé události vracet **původní** `state`, ne klon — proto `default: return { state, effects: fx }`.

```js
function timeout(s, now, fx) {
  switch (s.phase) {
    case 'countdown': return startRound(s, 0, now, fx);
    case 'drawing': return endRound(s, now, fx);
    case 'reveal':
      return s.roundIndex + 1 < s.roundMs.length
        ? startRound(s, s.roundIndex + 1, now, fx)
        : end(s, 'complete', fx);
    default: return { state: s, effects: fx };
  }
}

function end(s, reason, fx) {
  const totals = {};
  for (const id of s.order) totals[id] = s.players[id].total;
  s.phase = 'ended';
  s.deadline = 0;
  s.reason = reason;
  if (reason === 'forfeit') {
    s.winner = s.order.find(id => s.players[id].connected) ?? null;
  } else {
    const [a, b] = s.order;
    s.winner = totals[a] === totals[b] ? null : totals[a] > totals[b] ? a : b;
  }
  fx.push(
    alarm(null),
    send('all', { type: 'end', totals, winner: s.winner, reason }),
    { type: 'finish', totals, winner: s.winner, reason },
  );
  return { state: s, effects: fx };
}
```

- [ ] **Step 1: Napiš `MatchDO`**

Create `src/match-do.js`:

```js
import stations from '../web/stations.json';
import { weeklyChallenge, roundViewport } from '../web/shared/seed.mjs';
import { scoreRound } from '../web/shared/scoring.mjs';
import { validateRound } from '../web/shared/validate.mjs';
import { initialState, reduce, roundMsFor } from '../web/shared/duel-machine.mjs';
import { CODE_RE } from '../web/shared/code.mjs';

const TOKEN_RE = /^[0-9a-f]{16}$/;

export class MatchDO {
  constructor(ctx, env) {
    this.ctx = ctx;
    this.env = env;
  }

  // po hibernaci je instance prázdná — stav a kola se dopočítají z kódu a storage
  async load(code) {
    if (this.state) return;
    this.rounds = weeklyChallenge(code, stations);
    this.seats = (await this.ctx.storage.get('seats')) ?? {};
    this.state = (await this.ctx.storage.get('state'))
      ?? initialState(code, this.rounds.map(r => roundMsFor(r.station.lines.length)));
  }

  async fetch(request) {
    const url = new URL(request.url);
    const code = url.pathname.split('/').pop();
    if (!CODE_RE.test(code)) return new Response('bad code', { status: 400 });
    if (request.headers.get('upgrade') !== 'websocket') return new Response('expected websocket', { status: 426 });

    const token = url.searchParams.get('player') ?? '';
    if (!TOKEN_RE.test(token)) return new Response('bad player', { status: 400 });
    const nick = (url.searchParams.get('nick') ?? '').slice(0, 16) || 'hráč';
    const session = url.searchParams.get('session') ?? '';

    await this.load(code);
    await this.ctx.storage.put('code', code); // alarm si kód jinak nemá odkud vzít

    let seat = this.seats[token];
    if (!seat) {
      if (Object.keys(this.seats).length >= 2) return new Response('full', { status: 409 });
      seat = Object.values(this.seats).includes('a') ? 'b' : 'a';
      this.seats[token] = seat;
      await this.ctx.storage.put('seats', this.seats);
    }

    const [client, server] = Object.values(new WebSocketPair());
    server.serializeAttachment({ seat, code, session, ip: request.headers.get('cf-connecting-ip') ?? '' });
    this.ctx.acceptWebSocket(server, [seat]);
    await this.apply({ type: 'join', playerId: seat, nick }, Date.now());
    return new Response(null, { status: 101, webSocket: client });
  }

  async webSocketMessage(ws, raw) {
    const { seat, code } = ws.deserializeAttachment();
    let msg;
    try { msg = JSON.parse(raw); } catch { return; }
    if (msg.type !== 'submit') return;
    await this.load(code);

    const round = this.rounds[msg.i];
    if (!round) return;
    // úsečky musí ležet ve výřezu, který hráč dostal; neúplné kolo je za nulu
    const v = validateRound(msg.lines, round, { allowPartial: true });
    if (!v.ok) return;
    const complete = msg.lines.length === round.station.lines.length;
    const score = complete ? scoreRound(msg.lines, round.station).score : 0;
    await this.apply({ type: 'submit', playerId: seat, i: msg.i, score }, Date.now());
  }

  async webSocketClose(ws) {
    const { seat, code } = ws.deserializeAttachment();
    await this.load(code);
    await this.apply({ type: 'disconnect', playerId: seat }, Date.now());
  }

  async webSocketError(ws) {
    return this.webSocketClose(ws);
  }

  async alarm() {
    const code = await this.ctx.storage.get('code');
    if (!code) return;
    await this.load(code);
    await this.apply({ type: 'timeout' }, Date.now());
  }

  async apply(event, now) {
    const { state, effects } = reduce(this.state, event, now);
    this.state = state;
    await this.ctx.storage.put('state', state);
    for (const fx of effects) {
      if (fx.type === 'alarm') {
        await (fx.at === null ? this.ctx.storage.deleteAlarm() : this.ctx.storage.setAlarm(fx.at));
      } else if (fx.type === 'send') {
        this.send(fx.to, fx.msg);
      } else if (fx.type === 'finish') {
        await this.persist(fx);
      }
    }
  }

  send(to, msg) {
    const payload = this.enrich(msg);
    const sockets = to === 'all' ? this.ctx.getWebSockets() : this.ctx.getWebSockets(to);
    for (const ws of sockets) {
      const { seat } = ws.deserializeAttachment();
      try { ws.send(JSON.stringify({ ...payload, you: seat })); } catch { /* mrtvý socket */ }
    }
  }

  // automat neví nic o stanicích ani o hodinách klienta — doplní se to tady
  enrich(msg) {
    const out = { ...msg };
    if (out.deadline > 0) out.msLeft = Math.max(0, out.deadline - Date.now()); // proti rozjetým hodinám klienta
    if (out.type === 'round') {
      const st = this.rounds[out.i].station;
      out.viewport = roundViewport(this.rounds[out.i]);
      out.name = st.name;      // jméno je zadání kola, ne tajemství
      out.lines = st.lines;
    }
    if (out.type === 'reveal') {
      out.axes = this.rounds[out.i].station.axes;   // skutečné osy až po konci kola
    }
    return out;
  }

  async persist({ totals, winner, reason }) {
    const [a, b] = this.state.order;
    const nick = id => this.state.players[id]?.nick ?? '';
    try {
      await this.env.DB.prepare(
        `INSERT OR IGNORE INTO duels (code, nick_a, nick_b, score_a, score_b, winner, ended_reason)
         VALUES (?, ?, ?, ?, ?, ?, ?)`
      ).bind(this.state.code, nick(a), nick(b), totals[a] ?? 0, totals[b] ?? 0, winner, reason).run();
    } catch { /* výsledek v DB je bonus, zápas tím nepadá */ }
  }
}
```

```js
  `<line x1="${x1}" y1="${y1}" x2="${x2}" y2="${y2}" stroke="var(--draw)" stroke-width="4"

    + (anchor && cursor ? segMarkup([anchor, cursor], true) : '')

function commitSegment(a, b) {
  if (segs.length >= required) segs[segs.length - 1] = [a, b]; // další tah přepíše poslední úsečku

  else { anchor = p; cursor = p; pressing = true; }

    commitSegment(anchor, cursor);
    anchor = cursor = null;

  if (timerRaf) cancelAnimationFrame(timerRaf);
  timerRaf = null;
  timebar.hidden = true;
  clockEl.hidden = true;
  timebar.classList.remove('urgent');
  clockEl.classList.remove('urgent');

// totalMs: plná délka kola. onExpire se zavolá, až doběhne.
export function timerStart(totalMs, onExpire) {
  timerStop();
  total = totalMs;
  deadline = performance.now() + totalMs;
  expired = onExpire;
  timebar.hidden = false;
  clockEl.hidden = false;
  const bar = timebar.firstElementChild;
  const tick = now => {
    const left = Math.max(0, deadline - now);
    bar.style.transform = `scaleX(${left / total})`;   // pruh se poměřuje s původní délkou kola,
    $('clock-value').textContent = Math.ceil(left / 1000); // takže při shot clocku viditelně skočí dolů
    const urgent = left <= 5000;
    timebar.classList.toggle('urgent', urgent);
    clockEl.classList.toggle('urgent', urgent);
    if (left <= 0) { timerRaf = null; expired?.(); return; }
    timerRaf = requestAnimationFrame(tick);
  };
  timerRaf = requestAnimationFrame(tick);
}
```

```js
import * as board from './board.mjs';
import { newCode, CODE_RE } from './shared/code.mjs';

const $ = id => document.getElementById(id);
const overlay = $('overlay');

// token přežije reload stránky → server pozná, že jde o návrat, ne o třetího hráče
let token = sessionStorage.getItem('pmg-duel-token');
if (!token) {
  token = [...crypto.getRandomValues(new Uint8Array(8))].map(b => b.toString(16).padStart(2, '0')).join('');
  sessionStorage.setItem('pmg-duel-token', token);
}

let ws = null, you = null, code = null, roundIdx = 0, showCard = null, onLeave = null;

export function initDuel({ card, leave }) {
  showCard = card;   // app.mjs umí vykreslit kartu do overlaye
  onLeave = leave;   // návrat na úvodní obrazovku
}

export async function findOpponent() {
  const res = await fetch('/api/duel/queue', { method: 'POST' });
  const { code: c, host } = await res.json();
  connect(c, host ? 'Čekám na soupeře — vydrž, hledám ho ve frontě.' : 'Soupeř nalezen!');
}

export function hostDuel() {
  connect(newCode(), null);
}

export function joinDuel(c) {
  if (!CODE_RE.test(c)) return false;
  connect(c, null);
  return true;
}

function connect(c, note) {
  code = c;
  const nick = localStorage.getItem('pmg-nick') ?? 'hráč';
  const session = localStorage.getItem('pmg-session') ?? '';
  const url = new URL(`/api/duel/${code}`, location.href);
  url.protocol = url.protocol === 'https:' ? 'wss:' : 'ws:';
  url.search = new URLSearchParams({ player: token, nick, session });
  ws = new WebSocket(url);
  ws.onmessage = e => handle(JSON.parse(e.data));
  ws.onclose = () => { board.timerStop(); waitingCard('Spojení se serverem spadlo.', true); };
  $('confirm').onclick = submit;   // v duelu potvrzení posílá tip, nevyhodnocuje kolo lokálně
  document.body.dataset.phase = 'duel';
  $('duel').hidden = false;
  waitingCard(note ?? `Pošli kamarádovi odkaz — kód zápasu je ${code}.`);
}

function handle(msg) {
  you = msg.you ?? you;
  switch (msg.type) {
    case 'state': return onState(msg);
    case 'round': return onRound(msg);
    case 'deadline': return board.timerSetLeft(msg.msLeft);
    case 'opponent': return onOpponent(msg);
    case 'reveal': return onReveal(msg);
    case 'end': return onEnd(msg);
    case 'error': return waitingCard('Zápas je plný — tenhle kód už hrajou dva lidi.', true);
  }
}

function onState(msg) {
  const them = msg.players.find(p => p.id !== you);
  $('duel-name').textContent = them?.nick ?? 'soupeř';
  $('duel-me').textContent = (msg.players.find(p => p.id === you)?.total ?? 0).toLocaleString('cs');
  $('duel-them').textContent = (them?.total ?? 0).toLocaleString('cs');
  $('duel-flag').className = `duel-flag ${them && !them.connected ? 'gone' : ''}`;
  if (msg.phase === 'waiting') waitingCard(`Čekám na soupeře. Kód zápasu: ${code}`);
  if (msg.phase === 'countdown') waitingCard(`${them?.nick ?? 'Soupeř'} je tu. Začínáme!`);
  if (msg.phase === 'paused') waitingCard('Soupeř se odpojil — čekám 15 vteřin.');
  if (msg.phase === 'drawing' && !overlay.hidden) overlay.hidden = true; // návrat doprostřed kola
}

function onRound(msg) {
  roundIdx = msg.i;
  overlay.hidden = true;
  $('station-name').textContent = msg.name;
  $('round-label').textContent = `kolo ${msg.i + 1} z 10 · ${msg.lines.length > 1
    ? `přestup ${msg.lines.join('+')} · nakresli ${msg.lines.length} úsečky` : 'nakresli osu nástupiště'}`;
  $('line-badges').replaceChildren(...msg.lines.map(l => {
    const b = document.createElement('span');
    b.className = `badge ${l}`;
    b.textContent = l;
    return b;
  }));
  $('duel-flag').className = 'duel-flag waiting';
  $('clear').disabled = false;
  board.setRound(msg.viewport, msg.lines.length);
  board.maybeShowHint();
  board.timerStart(msg.msLeft, submit); // vypršení = odevzdej, co je nakresleno
}

function submit() {
  board.timerStop();
  $('confirm').disabled = true;
  $('clear').disabled = true;
  ws?.send(JSON.stringify({ type: 'submit', i: roundIdx, lines: board.segments() }));
}

function onOpponent(msg) {
  if (msg.id === you) return;
  $('duel-flag').className = `duel-flag ${!msg.connected ? 'gone' : msg.submitted ? 'submitted' : 'waiting'}`;
}

function onReveal(msg) {
  board.timerStop();
  board.revealAxes(msg.axes);
  $('duel-me').textContent = msg.totals[you].toLocaleString('cs');
  const themId = Object.keys(msg.totals).find(id => id !== you);
  $('duel-them').textContent = msg.totals[themId].toLocaleString('cs');
  const mine = msg.scores[you], theirs = msg.scores[themId];
  const verdict = mine === theirs ? 'Remíza v kole' : mine > theirs ? 'Kolo pro tebe' : 'Kolo pro soupeře';
  setTimeout(() => showCard(`
    <p class="label">kolo ${msg.i + 1} z 10</p>
    <h2>${verdict}</h2>
    <div class="big">${mine} : ${theirs}</div>
    <p>Další kolo za chvíli…</p>
  `), 1200);
}

function onEnd(msg) {
  board.timerStop();
  const themId = Object.keys(msg.totals).find(id => id !== you);
  const verdict = msg.reason === 'forfeit'
    ? (msg.winner === you ? 'Soupeř se odpojil — vyhrál jsi' : 'Odpojil ses — zápas propadl')
    : msg.winner === null ? 'Remíza' : msg.winner === you ? 'Vyhrál jsi!' : 'Prohrál jsi';
  showCard(`
    <p class="label">konec zápasu · ${code}</p>
    <h2>${verdict}</h2>
    <div class="big">${msg.totals[you]} : ${msg.totals[themId] ?? 0}</div>
    <button class="btn btn-primary" id="again">Nový duel</button>
    <button class="link-btn" id="back">← zpět na začátek</button>
  `, () => {
    $('again').onclick = () => { ws?.close(); sessionStorage.removeItem('pmg-duel-token'); location.href = '/?duel=new'; };
    $('back').onclick = () => { ws?.close(); onLeave(); };
  });
  ws = null;
}

  `, card => {
    card.querySelector('#duel-note').textContent = text; // text může nést nick → jen textContent
    if (dead) $('back').onclick = () => onLeave();
  });
}
```

- [ ] **Step 2: Zapisuj duelová kola z `MatchDO`**

V `src/match-do.js` přidej do `webSocketMessage` za výpočet skóre — potřebuje i `session` a `ip` z attachmentu, uprav proto první řádek metody:

```js
    const { seat, code, session, ip } = ws.deserializeAttachment();
```

a za `await this.apply(...)` přidej:

```js
    await this.logGuess({ session, ip, round, i: msg.i, segments: msg.lines, score, complete });
```

Novou metodu vlož za `persist`:

```js
  // stejný řádek jako /api/guess, jen ho zapisuje server sám — v duelu klient POST neposílá
  async logGuess({ session, ip, round, i, segments, score, complete }) {
    if (!/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i.test(session ?? '')) return;
    const r = complete ? scoreRound(segments, round.station) : null;
    const ipHash = await sha256(ip ?? '');
    try {
      await this.env.DB.prepare(
        `INSERT INTO guesses (session, mode, week, station_id, round_idx, u, v, segments_json,
                              dist_m, score, per_line_json, ms, timed_out, forfeited, ip_hash)
         VALUES (?, 'duel', ?, ?, ?, ?, ?, ?, ?, ?, ?, 0, 0, ?, ?)`
      ).bind(
        session, isoWeek(new Date()), round.station.id, i, round.u, round.v,
        JSON.stringify(segments), r?.d ?? null, score, r ? JSON.stringify(r.perLine) : null,
        complete ? 0 : 1, ipHash,
      ).run();
    } catch { /* statistika nesmí shodit zápas */ }
  }
```

Dvě nuly v `VALUES` jsou sloupce `ms` a `timed_out`: server neví, jak dlouho hráč kreslil, a vypršení času v duelu neznamená propadlé kolo (odevzdá se, co je nakresleno). Poslední dva otazníky jsou `forfeited` a `ip_hash` — dvanáct otazníků, dvanáct hodnot v `bind`.

Doplň chybějící importy na začátek `src/match-do.js`:

```js
import { weeklyChallenge, roundViewport, isoWeek } from '../web/shared/seed.mjs';
```

a pomocnou funkci nad třídu:

```js
async function sha256(s) {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(s));
  return [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, '0')).join('');
}
```
